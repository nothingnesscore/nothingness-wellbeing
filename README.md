# Nothingness Well-Being 🌿

A modern, highly optimized, and beautifully designed web application for "Nothingness Well-Being" — a person-centred counselling and psychology tutoring service based in Kolkata. 

Built with React, Tailwind CSS, and Framer Motion, this platform aims to provide a calming, zen-like experience reflecting the nature of the therapy it represents. It features advanced UI concepts such as fluid mesh gradient backgrounds, dynamic glassmorphism, responsive tab bars, and seamless dark mode toggling.

## 🚀 Technologies

- **React 18** (Create React App)
- **Tailwind CSS** (for utility-first styling)
- **Framer Motion** (for smooth, physics-based micro-animations)
- **Lucide React** (for crisp, minimal SVG iconography)
- **Cal.com** (embedded booking widget)
- **Vercel** (for deployment and analytics)

## ✨ Features

- **Fluid Mesh Gradient**: A performant, purely CSS-driven animated background that breathes and shifts.
- **Glassmorphic UI**: Premium frosted glass effects that refract the animated background below them.
- **Dark Mode**: Flawless system-aware light and dark modes with dedicated accessible color palettes for each state.
- **Performant Animations**: Heavily relies on CSS transforms and `framer-motion` to ensure 60fps scrolling and hover effects without heavy WebGL.
- **Fully Responsive**: Carefully tuned for mobile devices, tablets, and desktop displays.

## 🛠️ Local Development

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/nothingnesscore/nothingness-wellbeing.git
cd nothingness-wellbeing
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run start
```

Runs the app in the development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Build for Production

```bash
npm run build
```

Builds the app for production to the `build` folder.
It correctly bundles React in production mode and optimizes the build for the best performance.
